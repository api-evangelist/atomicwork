# Atomicwork Developer Documentation

> Programmatic access to the Atomicwork agentic service management platform. Manage requests, assets, users, workflows, and identity governance through REST APIs and MCP tools.

For clean Markdown of any page, append .md to the page URL.
For AI client integration (Claude Code, Cursor, etc.), connect to the MCP server at https://developers.atomicwork.com/_mcp/server.
